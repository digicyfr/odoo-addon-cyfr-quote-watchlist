# Quote Follow-up Watchlist dla Odoo 19

Bezpłatny, niezależnie instalowany moduł `cyfr_quote_watchlist` na licencji LGPL-3. Kod znajduje się w katalogu [`cyfr_quote_watchlist/`](cyfr_quote_watchlist/). Przeczytaj [polską instrukcję](cyfr_quote_watchlist/README.pl.md).

Gałąź `19.0` służy do utrzymania wersji Odoo 19. Gałąź `19.0.1.0.0` zawiera kod dokładnie tego wydania i pozostaje bez zmian po publikacji. Tag `cyfr_quote_watchlist-19.0.1.0.0` wskazuje archiwum ZIP, plik SHA-256 i dowody testów. Dodaj katalog repozytorium do ścieżki modułów Odoo 19, odśwież listę aplikacji i zainstaluj moduł. Przetestowano Odoo 19 Community; Enterprise pozostaje niezweryfikowany.

[Strona Digicyfr](https://www.digicyfr.com/pl/odoo/free-modules/cyfr_quote_watchlist) zawiera zrzuty ekranu i link do pobrania. Zgłaszaj błędy w Issues tego repozytorium bez haseł i danych klientów.
